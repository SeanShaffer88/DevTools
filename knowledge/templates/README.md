# Templates

Copy-ready starting points. A new project's first commit includes
its rule sheet (from the first template below) — that is part of
being under the system from day one (docs/01).

| File | What it is |
|---|---|
| [`project-rules-template.md`](project-rules-template.md) | The per-project rule sheet (the Elite Prompt's Appendix 7 shape): purpose, frozen foundation, build/gate commands, budgets, coverage floors, special rules. Fill it in at project start; update it in the same change as anything it describes. |
| [`QUALITY-template.md`](QUALITY-template.md) | The `QUALITY.md` skeleton: dimensions scored from evidence, the waiver log. Any Fail = not done (docs/04). |
| [`seanpak-template.json`](seanpak-template.json) | A starter `seanpak.json` packaging manifest (docs/08). Field names follow SeanPak's manifest format — check the SeanPak repo for the current schema before relying on a field. |

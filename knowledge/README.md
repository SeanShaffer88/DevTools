# DevTools

A self-contained knowledge base for building Windows desktop software
the way this family of projects is built: a layered rule system
(Elite Prompt → Engineering Contract → master prompts → project rule
sheet), tiered project classes with sanctioned stacks, a hard quality
gate, one packaging tool (SeanPak), one design system (TesselGUI),
and one release shape. Written for AI coding agents first and human
developers second.

## TL;DR

Building a Windows desktop program here means: classify the project
into its tier (docs/02), pick the tier's sanctioned stack, implement
every feature as an operation the GUI and CLI both call (docs/04),
follow the every-program rules (docs/06), theme it with TesselGUI
Carmine (docs/07), package it with SeanPak into exactly one installer
+ one portable zip + checksums (docs/08), and ship only when the
full gate passes and the release is verified by read-back (docs/09).
Software is free, offline, unsigned, and never on winget.

## Where this lives

This knowledge base is the `knowledge/` folder of the **DevTools**
repo, alongside that repo's Local Developer Toolkit (the
PowerShell/Python helper scripts at the repo root). The toolkit is
the tooling; this folder is the written system behind it.

## How an AI should use this repo

1. Read [AGENTS.md](AGENTS.md) first — the non-negotiable rules.
2. Read [docs/01-the-system-at-a-glance.md](docs/01-the-system-at-a-glance.md)
   for how the layers fit, then the doc for the task at hand.
3. Treat this repo as the distilled, operative form of the governing
   documents. [SOURCES.md](SOURCES.md) names the full texts and the
   companion projects (SeanPak, TesselGUI) and says what wins on
   conflict.
4. When a rule here would decide something expensive or
   irreversible, check the full source text named in SOURCES.md
   before acting.

## Using this repo with ChatGPT or another AI, locally

This repo is built to be downloaded and used offline by an AI:

1. Download the repo (Code → Download ZIP) and unzip it anywhere.
2. Point the AI at the repo's `knowledge/` folder. It should start with
   [manifest.json](manifest.json) (the file map and reading order)
   and [AGENTS.md](AGENTS.md) (the rules), then read in the manifest's
   order.
3. No time to load a folder? Upload [ai-bundle.md](ai-bundle.md)
   instead — the entire knowledge base concatenated into one markdown
   file. (Generated by [tools/build-ai-bundle.py](tools/); the bundle
   covers the docs and references — templates and tools stay as
   files, listed in the manifest.)

Everything is plain text/markdown with relative links; nothing here
needs a server, an account, or this repository's website.

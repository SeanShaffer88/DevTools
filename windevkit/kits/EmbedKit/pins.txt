# Pinned upstream artifacts. fetch.sh / fetch.ps1 refuse to proceed when
# a downloaded file's hash (SHA-512 for the runtime, SHA-256 for the test
# fixtures) does not match the pin. Bump = version +
# hash together, in one commit, and re-run the e2e embedding proof.
#
# ONNX Runtime (Microsoft, MIT) is a RUNTIME component: EmbedKit loads
# the user's libonnxruntime dynamically and never links or bundles it.
# This package is pinned so the e2e proof (and users who want a
# known-good source) have an exact, hash-verified runtime to point at.
# EmbedKit v0.1 speaks ONNX Runtime C API version 31 (ORT_API_VERSION
# in onnxruntime_c_api.h); newer runtimes stay compatible, older ones
# are reported precisely as EK_ERR_NOT_SUPPORTED.
# Source: Microsoft's official NuGet package Microsoft.ML.OnnxRuntime.
# The github.com/microsoft/onnxruntime repository and its release
# downloads were removed (404) around 2026-11-17; NuGet still serves the
# same native runtimes. One package holds both platforms:
#   runtimes/win-x64/native/onnxruntime.dll
#   runtimes/linux-x64/native/libonnxruntime.so
# The hash is NuGet's own packageHash (SHA-512) from its catalog, also
# served as the x-ms-meta-SHA512 header on the download.
ORT_VERSION=1.31.0
ORT_NUPKG_FILE=microsoft.ml.onnxruntime.1.31.0.nupkg

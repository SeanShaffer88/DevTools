# Prompt engineering and context engineering

Primary-source guidance from model providers beats folklore. Techniques are model-specific — check the guide for the model actually in use.

**9 resources.**

- **[Anthropic prompt engineering guide](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview)** — _Official docs._ Claude prompting: clarity, examples, XML structure, extended thinking.
- **[OpenAI prompt engineering guide](https://developers.openai.com/api/docs/guides/prompt-engineering)** — _Official docs._ Strategy and tactics for GPT-class models, plus reasoning-model guidance.
- **[Google Gemini prompting strategies](https://ai.google.dev/gemini-api/docs/prompting-strategies)** — _Official docs._ Gemini-specific prompting and media prompting.
- **[DAIR Prompt Engineering Guide](https://www.promptingguide.ai/)** — _Guide._ Comprehensive community guide: techniques, papers, RAG/agent prompting.
- **[Learn Prompting](https://learnprompting.org/docs/introduction)** — _Guide._ Free course-style prompting documentation, including security topics.
- **[Awesome ChatGPT Prompts](https://github.com/f/prompts.chat)** — _Repo / list._ Large prompt-pattern collection; useful as examples, not as verified best practice.
- **[Anthropic — Building Effective Agents](https://www.anthropic.com/research/building-effective-agents)** — _Article._ Anthropic's patterns: workflows vs agents, prompt chaining, routing, orchestrator-workers, evaluator-optimizer.
- **[Anthropic — Effective context engineering](https://www.anthropic.com/research/effective-context-engineering-for-ai-agents)** — _Article._ Context windows as a finite resource: compaction, note-taking, sub-agents.
- **[OpenAI — A Practical Guide to Building Agents (PDF)](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf)** — _Guide (PDF)._ OpenAI's practitioner guide: when to use agents, guardrails, orchestration patterns.

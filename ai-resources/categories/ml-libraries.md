# ML / DL libraries and training toolchains

The underlying frameworks. Pin versions from the project's own lockfiles; APIs differ materially across major versions.

**12 resources.**

- **[PyTorch documentation](https://pytorch.org/docs/stable/)** — _Official docs._ Tensors, autograd, distributed training, TorchServe/export.
- **[TensorFlow documentation](https://www.tensorflow.org/api_docs)** — _Official docs._ Keras-based training and deployment APIs.
- **[JAX documentation](https://docs.jax.dev/)** — _Official docs._ Composable transformations (grad/jit/vmap) for ML research.
- **[scikit-learn documentation](https://scikit-learn.org/stable/)** — _Official docs._ Classical ML: preprocessing, models, model evaluation — still the right tool for many tabular problems.
- **[Hugging Face PEFT](https://huggingface.co/docs/peft)** — _Official docs._ Parameter-efficient fine-tuning: LoRA and friends.
- **[Hugging Face TRL](https://huggingface.co/docs/trl)** — _Official docs._ SFT/DPO/RLHF training for Transformers models.
- **[Axolotl](https://github.com/axolotl-ai-cloud/axolotl)** — _Repo._ YAML-configured LLM fine-tuning (LoRA/full) across providers.
- **[LLaMA-Factory](https://github.com/hiyouga/LlamaFactory)** — _Repo._ Fine-tuning toolkit with web UI for 100+ models.
- **[Unsloth](https://github.com/unslothai/unsloth)** — _Repo._ Fast, memory-efficient LoRA/QLoRA fine-tuning notebooks and library.
- **[ONNX documentation](https://onnx.ai/onnx/)** — _Official docs._ Open model interchange format and ONNX Runtime for cross-platform inference.
- **[NumPy documentation](https://numpy.org/doc/stable/)** — _Official docs._ Array computing foundation of the Python ML stack.
- **[pandas documentation](https://pandas.pydata.org/docs/)** — _Official docs._ Tabular data manipulation; read the user guide section relevant to the task.

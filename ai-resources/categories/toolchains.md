# Toolchains by language and platform

Official docs, package registries, and standard tools per stack. An AI should check the official source for the exact stack in the project before recommending libraries or commands.

**30 resources.**

- **[Rust — rust-lang.org](https://www.rust-lang.org/)** — _Official site._ Language home; install via rustup, edition and release info.
- **[The Rust Book](https://doc.rust-lang.org/book/)** — _Official docs._ Canonical language tutorial; ownership, traits, error handling.
- **[crates.io](https://crates.io/)** — _Registry._ Rust package registry; check downloads, docs link, and maintenance before recommending a crate.
- **[docs.rs](https://docs.rs/)** — _Docs host._ Rendered docs for nearly every crate and version.
- **[Cargo Book](https://doc.rust-lang.org/cargo/)** — _Official docs._ Workspaces, features, profiles, publishing.
- **[Python — python.org](https://www.python.org/)** — _Official site._ Downloads, PEP index, release schedule.
- **[Python documentation](https://docs.python.org/3/)** — _Official docs._ Standard library reference; verify function behaviour here, not from memory.
- **[PyPI](https://pypi.org/)** — _Registry._ Python package index; check version, requires-python, and project links.
- **[uv](https://docs.astral.sh/uv/)** — _Tool docs._ Fast Python package/project manager from Astral; replaces pip/virtualenv workflows in many projects.
- **[Ruff](https://docs.astral.sh/ruff/)** — _Tool docs._ Python linter/formatter; rule reference is the source of truth for lint codes.
- **[Node.js](https://nodejs.org/en/docs)** — _Official docs._ Runtime APIs, LTS schedule, globals.
- **[npm](https://www.npmjs.com/)** — _Registry._ JavaScript package registry; verify package identity carefully — similar names are a supply-chain risk.
- **[TypeScript](https://www.typescriptlang.org/docs/)** — _Official docs._ Handbook, tsconfig reference, release notes.
- **[Deno](https://docs.deno.com/)** — _Official docs._ Secure JS/TS runtime, standard library, JSR registry.
- **[Bun](https://bun.sh/docs)** — _Official docs._ JS runtime, bundler, test runner, package manager.
- **[.NET documentation](https://learn.microsoft.com/en-us/dotnet/)** — _Official docs._ C#, F#, ASP.NET Core, MAUI, WPF/WinForms entry point.
- **[NuGet Gallery](https://www.nuget.org/)** — _Registry._ .NET package registry; check target frameworks and license per package.
- **[Go — go.dev](https://go.dev/doc/)** — _Official docs._ Language spec, effective Go, module reference.
- **[pkg.go.dev](https://pkg.go.dev/)** — _Docs host._ Discover and read docs for Go packages and the standard library.
- **[C++ reference (cppreference)](https://en.cppreference.com/)** — _Reference._ De-facto C/C++ standard library and language reference.
- **[CMake documentation](https://cmake.org/documentation/)** — _Official docs._ Build system generator used by most cross-platform C/C++ projects.
- **[vcpkg](https://vcpkg.io/)** — _Tool site._ Microsoft C/C++ package manager; port list is searchable online.
- **[Conan](https://conan.io/center)** — _Registry._ C/C++ package manager and Conan Center index.
- **[Java — dev.java](https://dev.java/)** — _Official site._ JDK tutorials, API docs, release information.
- **[Gradle](https://docs.gradle.org/)** — _Official docs._ Build tool for JVM/Android; DSL and plugin reference.
- **[Maven Central](https://central.sonatype.com/)** — _Registry._ JVM artifact registry; verify group/artifact coordinates.
- **[Git documentation](https://git-scm.com/doc)** — _Official docs._ Pro Git book and command reference.
- **[Docker documentation](https://docs.docker.com/)** — _Official docs._ Dockerfile reference, Compose spec, build best practices.
- **[Kubernetes documentation](https://kubernetes.io/docs/home/)** — _Official docs._ Concepts, kubectl reference, API reference.
- **[GitHub Docs](https://docs.github.com/)** — _Official docs._ Actions, REST/GraphQL APIs, Copilot, code security.

# Agent frameworks and orchestration

Frameworks for building agents and LLM applications. Prefer the project's existing framework; verify version-specific APIs in the framework's own docs — these APIs change fast.

**18 resources.**

- **[LangChain documentation](https://docs.langchain.com/)** — _Official docs._ LangChain + LangGraph docs: agents, tools, retrieval, streaming.
- **[LangChain (GitHub)](https://github.com/langchain-ai/langchain)** — _Repo._ Core LangChain monorepo.
- **[LangGraph](https://github.com/langchain-ai/langgraph)** — _Repo._ Stateful, durable agent orchestration as graphs; persistence and human-in-the-loop.
- **[LlamaIndex documentation](https://developers.llamaindex.ai/)** — _Official docs._ Data framework for RAG and agents: ingestion, indexes, query engines, workflows.
- **[LlamaIndex (GitHub)](https://github.com/run-llama/llama_index)** — _Repo._ LlamaIndex core and integrations.
- **[Microsoft Semantic Kernel](https://learn.microsoft.com/en-us/semantic-kernel/)** — _Official docs._ .NET/Python/Java AI orchestration SDK from Microsoft.
- **[Microsoft AutoGen](https://github.com/microsoft/autogen)** — _Repo._ Multi-agent conversation framework from Microsoft Research.
- **[CrewAI](https://docs.crewai.com/)** — _Official docs._ Role-based multi-agent crews and flows (Python).
- **[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)** — _Official docs._ OpenAI's lightweight agents SDK: agents, handoffs, guardrails, tracing.
- **[Claude Agent SDK (Anthropic docs)](https://code.claude.com/docs/en/agent-sdk/overview)** — _Official docs._ Anthropic's agent SDK for building agents on Muse.
- **[Google Agent Development Kit (ADK)](https://adk.dev/)** — _Official docs._ Google's open-source agent framework (Python/Java/Go).
- **[Haystack](https://docs.haystack.deepset.ai/docs/intro)** — _Official docs._ deepset's framework for production NLP/RAG pipelines and agents.
- **[DSPy](https://dspy.ai/)** — _Official docs._ Programmatic (compiled) LLM pipelines from Stanford NLP — declare, don't prompt-engineer by hand.
- **[Pydantic AI](https://pydantic.dev/docs/ai/overview/)** — _Official docs._ Type-safe Python agent framework from the Pydantic team.
- **[smolagents (Hugging Face)](https://huggingface.co/docs/smolagents)** — _Official docs._ Minimal agents library where agents write Python code as actions.
- **[Mastra](https://mastra.ai/docs)** — _Official docs._ TypeScript agent framework: agents, workflows, RAG, evals.
- **[Vercel AI SDK](https://ai-sdk.dev/docs)** — _Official docs._ TypeScript SDK for AI apps: streaming UI, tool calling, provider-agnostic models.
- **[Instructor](https://python.useinstructor.com/)** — _Official docs._ Structured outputs from LLMs via Pydantic validation and retries.

# Evaluation, observability, and guardrails

If you can't measure it, you can't ship it. Use evals before and after changes; tracing tools show what an agent actually did, not what you hoped it did.

**14 resources.**

- **[OpenAI Evals](https://github.com/openai/evals)** — _Repo._ OpenAI's eval framework and registry of benchmarks.
- **[promptfoo](https://www.promptfoo.dev/docs/intro/)** — _Official docs._ CLI-first LLM evals and red-teaming; test prompts/RAG/agents in CI.
- **[LangSmith documentation](https://docs.langchain.com/langsmith)** — _Official docs._ LangChain's tracing, datasets, and evaluation platform (works with other frameworks too).
- **[Langfuse documentation](https://langfuse.com/docs)** — _Official docs._ Open-source LLM observability: traces, evals, prompt management.
- **[Arize Phoenix](https://github.com/Arize-ai/phoenix)** — _Repo._ Open-source AI observability and evaluation notebooks/platform.
- **[Weights & Biases documentation](https://docs.wandb.ai/)** — _Official docs._ Experiment tracking, W&B Weave for LLM tracing/evals.
- **[MLflow documentation](https://mlflow.org/docs/latest/)** — _Official docs._ Open-source lifecycle platform: tracking, models, LLM evaluation and tracing.
- **[Ragas documentation](https://docs.ragas.io/)** — _Official docs._ RAG evaluation metrics: faithfulness, answer relevancy, context precision/recall.
- **[DeepEval](https://deepeval.com/docs/getting-started)** — _Official docs._ Unit-test-style LLM evaluation framework (Confident AI).
- **[Inspect AI (UK AISI)](https://inspect.aisi.org.uk/)** — _Official docs._ UK AI Security Institute's framework for rigorous model evaluations.
- **[Hugging Face Evaluate](https://huggingface.co/docs/evaluate)** — _Official docs._ Standard ML/NLP metrics library and leaderboard tooling.
- **[NVIDIA NeMo Guardrails](https://github.com/NVIDIA-NeMo/Guardrails)** — _Repo._ Programmable guardrails (Colang) for LLM apps.
- **[Guardrails AI](https://www.guardrailsai.com/docs)** — _Official docs._ Output validation/retry framework with a validator hub.
- **[OWASP Top 10 for LLM Applications](https://owasp.org/projects/top-10-for-large-language-model-applications)** — _Reference._ The security risk list for LLM apps: prompt injection, insecure output handling, training-data poisoning, etc. Read before shipping.

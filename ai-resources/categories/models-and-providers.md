# Models, hubs, and API providers

Where models live and who serves them via API. Pricing, context limits, and model names change constantly — always verify on the provider's live docs/pricing page.

**16 resources.**

- **[Hugging Face Hub](https://huggingface.co/models)** — _Hub._ The model/dataset hub: model cards carry license, files, and usage snippets. Read the card before recommending a model.
- **[Hugging Face documentation](https://huggingface.co/docs)** — _Official docs._ Transformers, Datasets, Diffusers, PEFT, TRL, and Hub APIs.
- **[Transformers documentation](https://huggingface.co/docs/transformers)** — _Official docs._ Model architectures and pipelines API reference.
- **[OpenAI platform documentation](https://developers.openai.com/api/docs)** — _Official docs._ API reference, models, reasoning, tools, and pricing links.
- **[Anthropic Claude documentation](https://docs.claude.com/)** — _Official docs._ Claude API, tool use, prompt engineering, and agent guidance.
- **[Google Gemini API documentation](https://ai.google.dev/gemini-api/docs)** — _Official docs._ Gemini models, function calling, embeddings, pricing.
- **[Meta Llama](https://dev.meta.ai/)** — _Official site._ Llama models, downloads, and responsible-use docs.
- **[Mistral AI documentation](https://docs.mistral.ai/)** — _Official docs._ Mistral models and API (chat, embeddings, OCR).
- **[Cohere documentation](https://docs.cohere.com/)** — _Official docs._ Command, Embed, and Rerank APIs — strong for enterprise RAG.
- **[Groq documentation](https://console.groq.com/docs)** — _Official docs._ Very fast inference API (LPU) for open models.
- **[Together AI](https://docs.together.ai/)** — _Official docs._ Hosted open-model inference, fine-tuning, and dedicated endpoints.
- **[Fireworks AI](https://docs.fireworks.ai/)** — _Official docs._ Fast hosted inference for open models and fine-tunes.
- **[Replicate](https://replicate.com/docs)** — _Official docs._ Run community and official models (LLMs, image, audio) via one API.
- **[OpenRouter](https://openrouter.ai/docs)** — _Official docs._ One API key routed to many providers/models; useful for comparison.
- **[arXiv](https://arxiv.org/)** — _Reference._ Preprint server — where most model papers land first. A paper is a claim, not a benchmark result.
- **[Papers With Code](https://huggingface.co/papers/trending)** — _Reference._ Papers linked to code and benchmark leaderboards (SOTA tables).

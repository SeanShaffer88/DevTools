# Local inference and model runners

Run models on your own hardware. Check model license, quantization formats, and hardware requirements upstream before recommending a download.

**12 resources.**

- **[Ollama](https://ollama.com/)** — _Tool site._ One-command local model runner (macOS/Windows/Linux) with an OpenAI-compatible API.
- **[Ollama (GitHub)](https://github.com/ollama/ollama)** — _Repo._ Source, model library format, API reference.
- **[llama.cpp](https://github.com/ggml-org/llama.cpp)** — _Repo._ GGUF inference in C/C++; the engine under many local tools. Supports CPU/GPU backends.
- **[vLLM](https://docs.vllm.ai/)** — _Official docs._ High-throughput LLM serving (PagedAttention), OpenAI-compatible server.
- **[SGLang](https://github.com/sgl-project/sglang)** — _Repo._ Fast serving framework with structured generation (RadixAttention).
- **[LM Studio](https://lmstudio.ai/)** — _Tool site._ Desktop app to discover, download, and serve local models with a GUI.
- **[MLX (Apple)](https://github.com/ml-explore/mlx)** — _Repo._ Apple's array framework for ML on Apple silicon; mlx-lm runs LLMs locally on Macs.
- **[whisper.cpp](https://github.com/ggml-org/whisper.cpp)** — _Repo._ Port of OpenAI Whisper speech recognition in C/C++ for local transcription.
- **[GPT4All](https://www.nomic.ai/gpt4all)** — _Tool site._ Nomic's local chatbot app and ecosystem.
- **[Jan](https://jan.ai/)** — _Tool site._ Open-source offline ChatGPT alternative desktop app.
- **[NVIDIA TensorRT-LLM](https://github.com/NVIDIA/TensorRT-LLM)** — _Repo._ Optimized LLM inference on NVIDIA GPUs for production serving.
- **[Hugging Face Text Generation Inference](https://huggingface.co/docs/text-generation-inference)** — _Official docs._ Production inference server for open models (TGI).

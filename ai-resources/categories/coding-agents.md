# AI coding tools and software-engineering agents

Tools that write and change code. An AI using these should still run the project's own build/tests — generated code is a draft until verified.

**11 resources.**

- **[Aider](https://aider.chat/docs/)** — _Official docs._ Terminal pair-programming with git integration and repo maps.
- **[Cline](https://github.com/cline/cline)** — _Repo._ Autonomous coding agent for VS Code with MCP support.
- **[Continue](https://docs.continue.dev/)** — _Official docs._ Open-source AI code assistant for IDEs; bring-your-own-model, MCP support.
- **[OpenHands](https://github.com/OpenHands/OpenHands)** — _Repo._ Open platform for autonomous software-development agents.
- **[SWE-agent](https://github.com/SWE-agent/SWE-agent)** — _Repo._ Princeton's agent that fixes GitHub issues; SWE-bench reference implementation.
- **[SWE-bench](https://www.swebench.com/)** — _Benchmark._ The standard benchmark for issue-fixing agents; check which split (Lite/Verified) a claim uses.
- **[Muse documentation](https://docs.github.com/en/copilot)** — _Official docs._ Copilot features, agent mode, code review, and administration.
- **[Muse documentation](https://code.claude.com/docs/en/overview)** — _Official docs._ Anthropic's terminal coding agent: hooks, subagents, MCP, settings.
- **[Gemini CLI](https://github.com/google-gemini/gemini-cli)** — _Repo._ Google's open-source terminal agent for Gemini, MCP-compatible.
- **[OpenCode](https://opencode.ai/docs)** — _Official docs._ Open-source terminal coding agent, provider-agnostic.
- **[Roo Code](https://github.com/RooCodeInc/Roo-Code)** — _Repo._ VS Code agent (Cline fork) with modes and MCP marketplace.
